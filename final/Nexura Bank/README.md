# Nexura Bank

## Overview

Nexura Bank is a digital banking platform that enables users to manage transactions in Bitcoin, Ethereum, Tether, and US Dollars. The application allows for depositing, withdrawing, exchanging, and transferring assets efficiently and securely.

## Features

- **Login System**: Secure authentication to ensure that access is granted only to valid users.
- **Asset Management**: Users can deposit, withdraw, and check their balances across multiple cryptocurrencies and fiat currencies.
- **Currency Exchange**: Facilitates the exchange between Bitcoin, Ethereum, Tether, and US Dollars directly within the platform.
- **Transfers**: Users can easily transfer funds to other users within Nexura Bank.

## Getting Started

### Prerequisites

Ensure you have Node.js installed on your system to use npm for managing dependencies and running the application.

### Installation

1. Install dependencies for the frontend:

```bash
npm install express uuid cookie-parser
npm install
```

2. Run the frontend applications:

```bash
npm run dev
```

This will start the frontend on http://localhost:5173

3. Set up and run the backend:

Open a new terminal then input

```bash
npm start
```

This will start the backend server on [http://localhost:3000](http://localhost:3000/)

## User Interface and Functionality

- **Login Screen**: Users are greeted by a login screen with textual prompts guiding them to input a valid username. Error messages will display if the input does not meet requirements.
- **Transaction Features**: During deposit, withdrawal, transfer, and exchange operations, users are guided by on-screen prompts to input required information accurately.
